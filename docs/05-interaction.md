# 05 使用体验

## 1. 按键归属：最重要的一条规则

很多"ssh 之后 TAB 补全失灵""vim 里快捷键被吃掉"的问题，根源都是终端**在不该拦按键的时候拦了按键**。Warp 早期把输入区换成了自己的编辑器，结果 ssh 到远程以后，远程 shell 的补全就用不了，只能靠额外的"远程适配"解决。

mooncli 的规则：**终端自己只在确认安全时处理按键，其它时候全部原样发给程序。**

### 三种状态

mooncli 为每个会话维护一个状态，由 shell 集成标记驱动：

```
           133;B（提示符结束，等待输入）
   ┌─────────────────────────────────────┐
   ▼                                     │
┌──────────┐  133;C（命令开始）  ┌──────────┐
│ 提示符上  │ ─────────────────► │ 程序运行中 │
│ (Prompt) │                    │ (Running) │
└──────────┘ ◄───────────────── └──────────┘
   ▲            133;D（命令结束）      │
   │                                  │ 进入全屏程序（切换到备用屏幕 ?1049h）
   │                                  ▼
   │                            ┌──────────┐
   └──── 退出备用屏幕 + 133;A ── │ 全屏程序  │
                                │ (AltScreen)│
                                └──────────┘
```

| 状态 | mooncli 处理的按键 | 原样透传的按键 |
| --- | --- | --- |
| **提示符上**（本机 pwsh 等待输入） | 补全面板、常驻面板选择键 | 其余全部，包括 TAB、→、Ctrl+R |
| **程序运行中**（ssh、claude、npm run…） | 只有"终端级"快捷键：新建/切换/关闭标签、复制粘贴、历史面板、命令面板 | 其余全部 |
| **全屏程序**（vim、htop、远程的 tmux） | 同上 | 同上 |
| **没有 shell 集成**（集成关了或加载失败） | 同"程序运行中" | 同上 |

关键点：

- **ssh 进去之后，本机 pwsh 处于"程序运行中"**（ssh 是它启动的一个程序），所以 TAB、Ctrl+Space 等都原样发给 ssh，再转给远程 shell。远程 bash/zsh 的补全照常工作。
- 远程 shell 如果也装了集成，会发出自己的 133 标记，但**不带本机 nonce**，mooncli 只用它来记录远程历史和显示远程目录，**不会因此进入"提示符上"状态去拦按键**。
- 终端级快捷键默认都带 `Ctrl+Shift`（`Ctrl+Shift+T` 新标签等），和 shell、vim 的常用键基本不撞。用户可以给任何一个快捷键加"运行中透传"标记。

### ssh 体验的其它保障

| 问题 | 做法 |
| --- | --- |
| 远程程序显示错乱、按键不对 | 环境变量 `TERM=xterm-256color` 会被 ssh 带到远程，这是所有服务器都认识的值 |
| 退格键在远程变成 `^H` | 退格发送 `DEL (0x7f)`，和 xterm 一致 |
| 浏览器把 TAB 当成"切换焦点" | xterm.js 的输入框会拦下 TAB；另外在外层容器上再保险一次，禁止任何 TAB 焦点切换逃出终端区 |
| Windows 自带的 OpenSSH 版本太老，出现按键或颜色问题 | 检测 `ssh.exe` 版本，过老时在标签上给一次性提示，建议用 `winget` 升级 |
| 远程想要目录、历史等智能功能 | 提供可选的远程集成脚本（bash / zsh / fish），一行命令装到服务器的 rc 文件里；不装也完全不影响使用 |
| 中文输入法在 ssh 里出不了字 | 输入法组合文字由 xterm.js 处理后以 UTF-8 发送，和本机一样；需要专项测试 |

## 2. 滚动

| 项 | 做法 |
| --- | --- |
| 触控板 | 像素级平滑滚动，跟手不跳行 |
| 鼠标滚轮 | 一格 3 行，带 120ms 的缓动动画（`smoothScrollDuration`）；可调或关闭 |
| 快速滚动 | `Shift+滚轮` 一次一屏 |
| 滚动条 | 默认细条、悬停变粗；滚动条上标出**每个命令的位置**（小点），失败的命令标红点，点一下跳过去 |
| 按命令跳转 | `Ctrl+↑ / Ctrl+↓` 跳到上一个/下一个提示符（靠 133;A 标记） |
| 输出时不打扰 | 往上翻看历史时，新输出不会把视图拉回底部；右下角出现"↓ 有新输出"小按钮 |
| 全屏程序 | vim、less 里的滚轮转换成方向键或鼠标事件发给程序（xterm.js 自带） |

帧率目标：普通滚动稳定 60fps，120Hz 屏幕上跟随刷新率。

## 3. 选择

| 操作 | 效果 |
| --- | --- |
| 拖动 | 普通选择 |
| 双击 | 选中一个"词"。词的边界按终端习惯调整：路径 `C:\a\b.txt`、URL、`foo-bar_baz` 都算一个词 |
| 三击 | 选中一行（自动换行的长行算一整行） |
| `Alt+拖动` | 矩形选择（选表格的某几列） |
| `Shift+单击` | 从上次选择处扩展到这里 |
| 单击命令左侧的小圆点 | 选中**这条命令的全部输出**（靠 133 标记划分命令块） |

## 4. 复制

| 操作 | 效果 |
| --- | --- |
| `Ctrl+C` | **有选中内容时复制**，没有时发送中断信号给程序（和 Windows Terminal 一致） |
| `Ctrl+Shift+C` | 总是复制 |
| 选中即复制 | 可选开关，默认关 |
| 右键 | 默认：有选中时复制，没有时粘贴（和 Windows Terminal 一样）。设置里可改成"弹出菜单"（复制、粘贴、全选、清除屏幕）；`Shift+右键`总是弹出菜单 |
| 命令块菜单 | 命令左侧小圆点的菜单：复制命令、复制输出、复制命令+输出、重新执行 |

**"已复制"小卡片**：复制成功后弹出一张横向的小卡片，写着"已复制 · 3 行 · 128 字"（单行时是"12 个字"）。

- 位置：右键复制时在右键处；按 `Ctrl+C` 时在刚才松开鼠标的地方（15 秒内），否则在选区末尾；从菜单里复制路径时在菜单打开的地方。卡片放在这个点的正上方，上面放不下就放下面，不会出窗口。
- 动效：弹性放大出场（带一点模糊到清晰），左侧的 mooncli 月亮图标从左下方转着升起、摆正，外圈泛起一圈涟漪；停留 0.9 秒后向上飘走并淡出。总共约 1.2 秒，不挡操作（鼠标可以穿过它）。
- 系统开了"减少动画"时只淡入淡出。设置里可以关掉。

复制时的清理（都有开关，默认开）：

- 去掉每行末尾多余的空格（终端用空格填满行，复制出来很难看）。
- 自动换行的长行复制出来是一行，不会被切断。
- 复制提示符+命令时可选只复制命令部分。

## 5. 粘贴

| 操作 | 效果 |
| --- | --- |
| `Ctrl+V` / `Ctrl+Shift+V` / `Shift+Insert` | 粘贴 |
| 右键（无选中时） | 粘贴 |

**剪贴板由 Rust 端读写**（`arboard` 库，调用系统剪贴板接口），不用网页的 `navigator.clipboard`。网页读剪贴板时 WebView2 会弹出"允许读取剪贴板"的权限提示，改走系统接口后就不会再弹。

粘贴时的保护：

- **括号粘贴模式**：程序（PSReadLine、bash、vim）开启了这个模式时，粘贴内容用特殊标记包起来，程序知道这是粘贴不是手打，多行内容不会被一行行执行。
- **多行粘贴确认**：程序没开括号粘贴、内容又有多行时，弹出确认条："将粘贴 12 行，可能会逐行执行"，显示前几行预览，`Enter` 确认、`Esc` 取消。
- **大段粘贴**：超过 4KB 时分块写入 ConPTY（每块 1KB，间隔 1ms），避免 ConPTY 或远程端丢字。
- **危险内容提示**：粘贴内容里有 `rm -rf /`、`Format-Volume`、`curl … | sh` 这类模式时，在确认条上标出来。
- **剪贴板里是图片**：可选把图片存成临时文件，粘贴文件路径（方便给 Claude Code 发截图）。
- 智能引号、全角空格等不可见字符替换成普通字符（可关）。

## 6. 点击

- `Ctrl+单击`：打开链接、文件路径（`src/main.ts:42:7` 用设置的编辑器打开到对应行）、目录（在新标签页打开）。
- 悬停在路径/链接上时显示下划线和提示，不按 Ctrl 不会误触。
- 在提示符上，单击输入行的某个位置可以把光标移过去（发送对应数量的 ←/→），可关闭。

## 7. 搜索

`Ctrl+Shift+F` 在当前终端的输出里搜索：支持大小写、全词、正则；所有匹配项高亮，滚动条上标出位置。

## 8. 其它手感细节

| 项 | 做法 |
| --- | --- |
| 光标 | 竖线 / 方块 / 下划线可选；默认竖线，平滑移动动画 60ms；窗口失焦时变成空心方块 |
| 输入法 | 候选框跟随光标；组合中的文字带下划线；切换中英文不影响快捷键 |
| 响铃 | 默认不发声，标签页闪一下；后台标签页响铃时标签上出现小圆点 |
| 窗口拖动 | 标题栏空白处拖动；双击最大化；Windows 11 贴靠布局（悬停最大化按钮）可用 |
| 快速唤出 | 可选全局快捷键（如 `Win+`` `）唤出/隐藏窗口，像 Quake 下拉终端 |
| 命令面板 | `Ctrl+Shift+P`（或点标题栏的搜索框）：搜索操作（新建、复制标签页、缩放、清屏、复制当前目录……）、切换主题、切换标签页，以及**历史命令**（Rust 端历史库模糊搜索，同目录优先）。历史命令按 `Enter` 填入当前标签页，`Shift+Enter` 直接运行；当前程序不在 pwsh 提示符上时，历史命令变灰，避免把文字塞给正在运行的程序。支持英文别名（输入 zoom 能找到"放大"） |
| 右键菜单 | 不用 WebView 自带的菜单（刷新、另存为、打印这些在终端里没有意义）。标签页、侧栏空白处、终端里的右键都是自己画的菜单，见 [06](06-smart-tabs.md) §6 |
| 分屏 | `Alt+Shift+=` 左右分、`Alt+Shift+-` 上下分，`Alt+方向键` 切换窗格（和 Windows Terminal 一致） |

## 9. 快捷键默认表（终端级）

**每个操作的快捷键都能改**（设置 → 快捷键，实现在 `app/src/shortcuts.ts`）：

- 点"+ 添加"后直接按下想要的键；一个操作可以有好几个键；点 × 去掉；改过的旁边有"恢复默认"。
- 新的键已经被别的操作占用时，自动从那个操作上拿过来，并提示一句。
- 设的键在终端里原本有用处（比如 `Ctrl+B` 是 shell 的"光标左移"、也是 tmux 的前缀键，`Ctrl+R` 是 shell 自己的历史搜索）时，提示它原本的用途，用户自己决定。这类键在列表里带黄色描边。
- 两套预设：**默认**（都用 Ctrl+Shift 组合，不占用 shell 和 vim 的键）、**VS Code / 浏览器习惯**（`Ctrl+B` 收起标签栏、`Ctrl+T` 新建、`Ctrl+W` 关闭、`Ctrl+R` 历史）。
- 按物理键位识别，换键盘布局不影响；`Alt+1…9`、复制粘贴这些固定的键也列在页面上方便查。
- 默认没有快捷键、但可以自己加的操作：重命名、置顶标签页、终端字号加大/减小、清屏、换主题、复制当前目录路径。

默认值：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+T` | 新标签页（默认配置档） |
| `Ctrl+Shift+1…9` | 用第 N 个配置档新建标签页 |
| `Ctrl+Shift+W` | 关闭当前窗格/标签页 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换标签页 |
| `Alt+1…9` | 跳到第 N 个标签页 |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+Shift+R` | 历史面板 |
| `Ctrl+Shift+F` | 搜索输出 |
| `Ctrl+Shift+B` | 显示/隐藏侧边标签栏 |
| `Ctrl+Shift+A` | 显示/隐藏 Agent 用量小窗 |
| `Ctrl+,` | 设置 |
| `Ctrl+= / Ctrl+- / Ctrl+0` | 整体缩放（界面和终端一起） |
| `Ctrl+滚轮` | 只调终端字号 |
| `Ctrl+,` | 设置 |
| `Ctrl+↑ / Ctrl+↓` | 跳到上/下一条命令 |
