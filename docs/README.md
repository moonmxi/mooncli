## 第一次读的建议

- 只想知道大概：读 00 和 09 的里程碑表。
- 要开始写代码：00 → 01 → 02，再读自己负责的功能文档。
- 做视觉：08 + 打开 `design/mockup/index.html`。

## 写文档的约定

- 用大白话。新概念第一次出现时解释一句。
- 对外部工具（Claude Code、Codex、PSReadLine 等）行为的描述，凡是会随版本变化的，标注 **【待核实】**，动手实现前按当时的官方文档再确认一遍。
- 设计改了，文档跟着改，在同一个 PR 里。
