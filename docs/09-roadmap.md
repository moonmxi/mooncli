# 09 实现计划

## 1. 里程碑总览

按"先能用、再好看、再聪明"的顺序。每个里程碑结束时都要能打包出一个可以日常使用的版本。时间按一个人业余开发估算，仅供参考。

| 里程碑 | 目标 | 估时 | 完成后能做什么 |
| --- | --- | --- | --- |
| **M0 骨架** | 工程搭好，CI 跑起来 | 1 周 | 打开一个空窗口 |
| **M1 能用的终端** | ConPTY + pwsh + xterm.js，多标签 | 3 周 | 替代 Windows Terminal 做日常简单使用 |
| **M2 shell 集成** | 提示符/命令/目录标记，历史入库 | 2 周 | 标签页显示目录、命令成败；Ctrl+↑↓ 跳命令 |
| **M3 外观系统** | 主题、字体、背景、Mica、设置界面 | 3 周 | 五套主题、背景图、热更新 |
| **M4 命令记忆** | 历史面板、补全面板、常驻面板 | 3 周 | 重点功能二全部可用 |
| **M5 智能标签** | 标题沿用、程序识别、图标、提醒、分屏 | 2 周 | 重点功能四（标签部分）可用 |
| **M6 Agent 小窗** | bridge、Claude Code / Codex 接入、小窗 | 2 周 | 重点功能四（用量部分）可用 |
| **M7 打磨发布** | 性能、安装包、自动更新、文档 | 2 周 | 1.0 版 |

M3 和 M2 之间没有依赖，有两个人时可以并行。

### 用户反馈修正（第五轮）

| 反馈 | 原因 | 处理 |
| --- | --- | --- |
| 侧栏底部"主题"在某些宽度会溢出 | 三个按钮固定带文字，只按侧栏的三档宽度切换，中间的宽度放不下 | 按钮按底部栏自身的可用宽度决定：先收紧间距，再窄就只留图标（字号、界面缩放变了也跟着变） |
| 历史详情里执行记录多了，命令框被压扁 | 详情区是纵向弹性布局，内容多时各块一起被压缩 | 命令框、按钮、统计固定高度，整列一起滚动 |
| 历史面板很卡 | 面板跟着整个标签页的数据走，标签页标题、计时一变就重新查询、重画三百行；按主机筛选走数据库，十万条时 136ms | 只取需要的几项；每行单独缓存；主机、目录、成败、收藏筛选都进内存索引（约 7ms）。移动选中从平均 80ms 降到 36ms |
| 需要更多快捷键，比如 Ctrl+B 收起标签栏 | — | 每个操作的快捷键都能改、能录、有冲突提示和两套预设（docs/05 §9） |
| 识别 sshp | — | 内置 sshp、sshpass，并可在设置里加自己的连接命令（docs/06 §4.1） |
| 没有 pwsh 7 怎么办 | 原来会悄悄换成 Windows PowerShell 5.1 | 显示说明页：一键用 winget 安装、去官网下载、临时用 5.1、指定位置（docs/02 §3.1） |
| 强化数据管理 | — | 设置每天自动备份并可恢复、整体导出导入、占用空间、背景图管理、历史保留天数（docs/03 §7） |
| 新建标签页后切回原标签页出现乱码 | 各终端共用一份字形贴图，新终端加载字体后清空了贴图，老终端手里的字形位置失效 | 任何终端清贴图时让全部终端重画，切回标签页时也重画一次 |

## 3. 性能指标

| 指标 | 目标 | 怎么测 |
| --- | --- | --- |
| 冷启动到提示符出现 | < 800ms（不含用户 profile 耗时） | 启动时打点 |
| 新建标签页到提示符 | < 300ms（不含 profile） | 同上 |
| 按键到屏幕显示 | 比 Windows Terminal 多不超过 5ms | Typometer 类工具对比测试 |
| 大量输出 | `Get-Content` 一个 100MB 文件，界面不卡死，可随时 Ctrl+C | 手动 + 脚本 |
| 滚动帧率 | 60fps（有背景图 + Mica 时也是） | Chrome DevTools 性能面板 |
| 内存 | 1 个标签页 < 150MB，每多一个标签 < 25MB（1 万行回滚） | 任务管理器 |
| 空闲 CPU | 窗口在后台时 < 0.5% | 同上 |

## 5. 风险和对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| xterm.js 在 WebView2 里的性能不如原生 | 大量输出时卡 | 批处理 + 背压；WebGL 渲染；M1 就做压测，不达标早调整 |
| 悄悄发组合键取补全，和用户快速输入抢顺序 | 输入错乱 | 只在提示符上且用户停顿时发；M4 专项测试；常驻面板默认不用这个来源 |
| Claude Code / Codex 的数据格式变化 | 小窗数据错误或消失 | 所有解析都容错；字段缺失就显示"不可用"；样本文件进测试，版本更新时快速对比 |
| 拿不到官方额度数据 | 5h/周额度只能估算 | 明确标"≈"，提供校准；有官方字段后立刻切换 |
| ConPTY 的已知问题 | 显示错乱 | 自带新版 conpty.dll；保留系统 ConPTY 开关方便对比排查 |
| 用户 profile 很慢 | 启动慢被算到 mooncli 头上 | 启动页显示"正在加载 PowerShell 配置文件…"及耗时，帮用户定位 |
