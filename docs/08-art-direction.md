# 08 美术风格与版面

## 1. 风格关键词

**安静、明亮、有纸感。**

- 名字叫 mooncli，视觉上取"月光下的纸面"：底色不是纯白，而是带一点温度的米白、雾蓝、樱粉、青瓷；强调色像月光一样柔和，不刺眼。
- 界面元素尽量"退后"：边框很淡，阴影很浅，大部分层次靠底色的细微深浅来区分，让终端文字始终是主角。
- 小面积的精致细节：月相图标、呼吸的状态点、柔和的过渡动画。

不要的东西：大面积高饱和色、粗边框、重阴影、霓虹发光、拟物质感。

## 2. 配色

五套内置主题，前四套浅色，最后一套深色作为夜间搭配。完整色值见 [`design/themes/`](../design/themes/)，下表是核心色。

| 主题 | 气质 | 底色 surface0 | 面板 surface1 | 悬停 surface2 | 正文 | 次要文字 | 强调色 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **月白 Moon Paper**（默认） | 暖调纸白，长时间看不累 | `#FAF8F3` | `#F2EFE7` | `#E9E5DA` | `#2F2D29` | `#68645A` | `#5B6FA8` 月光蓝 |
| **霜蓝 Frost** | 冷调蓝灰，清爽 | `#F5F8FB` | `#ECF1F6` | `#E1E8F0` | `#232B36` | `#5B6776` | `#2F6FB0` 晴空蓝 |
| **樱晨 Sakura Dawn** | 粉调晨光，柔和有温度 | `#FCF7F7` | `#F6EEEF` | `#EEE3E5` | `#352C30` | `#716268` | `#B8566F` 樱色 |
| **青瓷 Celadon** | 淡青灰绿，安静克制 | `#F4F7F4` | `#EBF0EC` | `#E0E8E2` | `#26312B` | `#5B6961` | `#3F7F64` 青瓷绿 |

### 用色规则

- **三层底色**：`surface0` 是终端和窗口底；`surface1` 是标签栏、侧栏、面板；`surface2` 是悬停、按下、输入框。相邻两层的明度差控制在 3%–5%，看得出层次但不跳。
- **强调色只用在"当前"和"需要注意"上**：当前标签的指示条、选中项、光标、进度条、提醒小点。一屏里强调色面积不超过 5%。
- **状态色**：成功、警告、危险三色都取自该主题的 ANSI 绿、黄、红，保证终端输出和界面提示颜色一致。
- **对比度**：正文 ≥ 7:1，次要文字 ≥ 4.5:1，图形元素（图标、进度条）≥ 3:1。由 `tools/check_contrast.py` 自动检查，新主题进仓库前必须通过。

### ANSI 16 色的调法

浅色主题的 ANSI 色和深色主题思路相反：

- 普通八色都要"压暗"到在浅底上 ≥ 4.5:1，饱和度适中，避免荧光感。
- `yellow` 是最难的一个：纯黄在浅底上几乎看不见，所以改成接近琥珀/土黄的 `#8A6410` 一类。
- `white`、`brightWhite`：程序用它们时通常以为背景是黑的。浅色主题把它们设成中灰（≥ 3:1），保证"白字"依然可读。
- `brightBlack` 常用于注释和 PSReadLine 的灰色联想，设成 3:1 左右的暖灰，既清楚又明显比正文淡。

## 3. 字体

| 用途 | 字体 | 字号 / 行高 |
| --- | --- | --- |
| 终端 | Cascadia Code → Microsoft YaHei UI → Nerd Font 符号（推荐用户装 Maple Mono NF CN） | 14px / 1.25 |
| 界面正文 | Segoe UI Variable Text → Microsoft YaHei UI | 13px / 1.45 |
| 界面小字（第二行状态、时间） | 同上 | 11.5px / 1.4，次要文字色 |
| 面板标题 | Segoe UI Variable Display，半粗 600 | 13px，字间距 0.2px |
| 数字（用量、时长） | 界面字体 + 等宽数字（`font-variant-numeric: tabular-nums`） | 跟随所在位置 |

## 4. 间距、圆角、阴影

- **4px 网格**：所有间距是 4 的倍数，常用 4 / 8 / 12 / 16 / 24。
- **圆角**：窗口 8px（跟随 Windows 11）；卡片、面板、弹层 10px；按钮、输入框、标签项 6px；状态小点圆形。
- **阴影**（浅色主题）：
  - 浮层（历史面板、补全面板）：`0 8px 24px rgba(40, 35, 25, 0.10), 0 1px 3px rgba(40, 35, 25, 0.08)`
  - 浮动卡片（Agent 小窗）：`0 4px 16px rgba(40, 35, 25, 0.08)`
  - 其它元素不用阴影，用 1px `border` 色分隔。
- **边框**：1px `border` 色，只在需要分隔的地方用；侧栏和终端之间用分隔线，不用阴影。

## 5. 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 悬停变色 | 120ms | ease-out |
| 面板弹出 | 160ms，从上方 6px 位移 + 淡入 | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| 侧栏展开/收起 | 200ms | 同上 |
| 标签切换指示条滑动 | 180ms | 同上 |
| 运行中状态点"呼吸" | 1.6s 循环，透明度 0.4 ↔ 1 | ease-in-out |
| 背景图切换 | 600ms 交叉淡入淡出 | linear |

- 跟随系统"减少动画"设置：开启时所有位移动画变成直接切换，呼吸点变成常亮。
- 动画只用 `transform` 和 `opacity`，不触发重排，保证不影响终端渲染帧率。

## 6. 图标

- 界面图标用 **Fluent UI System Icons**（微软开源，MIT 协议），线性风格、1.5px 线宽，和 Windows 11 一致。
- 程序类型图标（git、node、python、ssh…）统一重绘成同样的线性风格单色图标，颜色跟随文字色，当前标签上跟随强调色。
- Agent 图标：风格化的简单图形，不直接用官方 logo（见 [06](06-smart-tabs.md)）。
- **品牌标志**：一弯新月托着一个 `>_` 提示符，单色线稿。应用图标在浅底上用强调色月光蓝，深底上反白。
- 月相作为小彩蛋：空闲的配置档图标可选"月相"，按当天真实月相显示。

## 8. 关键组件细节

### 标签项（竖排，四种状态）

```
 常态     │  ⎇ 发布脚本          ✓ │   图标、标题用次要文字色
          │    scripts · main      │
 悬停     │▒ ⎇ 发布脚本          ✓ │   底色 surface2
 当前     │▌ ✳ 重构标签布局      ● │   底色 surface0，左侧强调色竖条，标题用正文色、半粗
 需要注意 │  ✳ 修复 ssh 补全    (●)│   状态点用强调色并有一圈 2px 光环，标题加粗
```

### 状态小点

| 状态 | 样子 |
| --- | --- |
| 运行中 | 6px 圆点，强调色，呼吸动画 |
| 成功 | 小号 ✓，成功色 |
| 失败 | 小号 ✗ + 退出码，危险色 |
| 等你操作 | 8px 圆点，强调色，外圈 2px 半透明光环 |

### 面板列表项

- 高 32px（历史）/ 28px（补全），左右内边距 12px。
- 左：来源图标（历史 ↺、命令说明书 ⎇、路径 📁、pwsh 补全 ƒ），16px，次要文字色。
- 中：候选文字，等宽字体；匹配到的字符用强调色 + 半粗。
- 右：附加信息（目录、次数、时间、说明），次要文字色，过长时截断。
- 选中项：`accentSoft` 底色，圆角 6px，左右各缩进 4px。

### 命令块

- 每条命令左侧边距里有一个 6px 小圆点：成功是次要文字色的空心圆，失败是危险色实心圆，运行中是强调色呼吸点。
- 悬停一个命令块时，整个块的底色变成 `surface1` 的 40% 透明度，左侧出现 2px 竖线，表示"这一块是一条命令"。
- 默认很低调，不加分隔线；可在设置里开启"命令之间显示细分隔线"。

## 9. 背景图美术方向

浅色背景图的要求：

- **低对比、留白多**：主体放在角落（默认右下），终端主要文字区域保持接近纯色。
- **整体明度 ≥ 85%**，避免压暗文字区。
- **色调和主题呼应**：月白配暖调纸纹或晨雾，霜蓝配冷色海面或雪山远景，樱晨配淡樱枝，青瓷配竹影或水墨远山。
- **内置四张**（需要自制或选可商用授权素材）：
  1. 晨雾（月白）：浅米色渐变 + 右下角淡淡的山的轮廓
  2. 冷海（霜蓝）：浅蓝灰渐变 + 底部极淡的波纹线
  3. 樱枝（樱晨）：右上角一枝浅粉樱花，其余留白
  4. 月面（通用）：右下角一个极淡的月球表面局部，灰度
- 默认蒙版 60%、模糊 0、图片不透明度 35%。用户换图后，如果检测到图片在文字区平均明度低于 85%，自动建议调高蒙版。

## 10. 原型

[`design/mockup/index.html`](../design/mockup/index.html) 是一个静态的版面原型，用浏览器打开即可：

- 切换五套主题，看各区域的配色效果；
- 切换左侧 / 顶部两种标签栏布局，收起 / 展开侧栏；
- 打开历史面板、补全面板、Agent 小窗，看浮层的样式。

原型只用来对齐视觉，不是实际代码；正式实现以本文档的规格为准。
