# 06 智能标签页

## 1. 两种布局

用户在设置里选，随时切换（`tabs.position`）：

| 布局 | 适合 | 样子 |
| --- | --- | --- |
| **左侧竖排**（默认） | 标签多、想看清每个标签的状态 | 窗口左边一列，每个标签两行：标题 + 状态行 |
| **顶部横排** | 标签少、想要更宽的终端 | 融进标题栏，像浏览器 |

具体版面尺寸见 [08 美术风格与版面](08-art-direction.md)。

## 1.1 侧栏缩放

左侧标签栏的宽度可以用鼠标拖动右边缘调整，内容会随宽度自动换一种排法。

**拖动规则：**

| 操作 | 效果 |
| --- | --- |
| 拖动侧栏右边缘 | 在 160–360px 之间连续调整；手柄的可拖区域宽 6px，悬停时分隔线变成 2px 强调色，光标变成左右箭头 |
| 拖到 120px 以下松手 | 吸附成收起状态（52px） |
| 从收起状态往右拖过 100px | 展开到 160px，继续拖可以更宽 |
| 双击手柄 | 在"收起"和"上次的展开宽度"之间切换 |
| `Ctrl+Shift+B` | 同双击 |
| 键盘 | 手柄可以用 Tab 选中，`←/→` 每次调 16px，`Enter` 切换收起（照顾不方便用鼠标的情况） |

拖动时实时跟随鼠标，终端区域同步改变尺寸；ConPTY 的改尺寸调用做 50ms 防抖，松手后再补一次，避免拖动过程中 pwsh 反复重绘。宽度按窗口记住，下次打开恢复。

**内容随宽度变化（四档）：**

| 档位 | 宽度 | 每个标签显示 |
| --- | --- | --- |
| 收起 | 52px | 只有图标；状态小点叠在图标右上角；悬停弹出完整信息 |
| 紧凑 | 160–199px | 一行：图标 + 标题 + 状态，行高 36px；目录等第二行信息放进悬停提示 |
| 标准 | 200–279px | 两行：标题 + 状态 / 目录 · 分支 · 程序，行高 52px（默认 220px） |
| 宽 | 280–360px | 两行，第二行显示更完整的路径；运行时长等附加信息常显 |

分组标题、"新标签页"按钮、底部的设置入口也跟着档位变化：收起时只剩图标，紧凑档文字缩短（"新标签页" → "新建"）。

## 1.2 响应式布局

窗口变窄时，先保证终端够宽（目标至少 80 列，绝对不少于 60 列），再考虑侧栏和右侧面板。规则按窗口宽度分四段：

| 窗口宽度 | 左侧栏 | 右侧面板（历史 / 补全 / Agent） | 其它 |
| --- | --- | --- | --- |
| ≥ 1280px | 用户设定的宽度 | 可以并排停靠 | 全部正常 |
| 960–1279px | 用户设定的宽度 | 打开时**浮在终端上方**（抽屉式），不挤压终端；钉住时才停靠 | — |
| 720–959px | 自动收起成 52px | 只能浮层 | 标题栏的命令面板入口缩成一个搜索图标；Agent 小窗自动切换到状态栏模式 |
| < 720px | 隐藏，标题栏左侧出现 ☰ 按钮，点开后侧栏以浮层形式滑出 | 只能浮层 | 状态栏只保留目录和 Agent 摘要 |

- **自动收起不覆盖用户设定**：窗口变宽后恢复用户原来拖出来的宽度。
- 用户可以在设置里关掉自动收起（`tabs.sidebar.autoCollapse: false`），这时窗口再窄也保持展开，由终端让出空间（但仍不少于 60 列，不够时侧栏改为浮层）。
- 换算方式：用当前字体的字符宽度乘列数得到终端需要的最小宽度，所以字号越大，越早触发收起。上面的像素值是 14px Cascadia Code 时的近似值。
- 窗口最小尺寸 480 × 320px。
- 顶部横排布局下，标签按 220 → 120px 逐步压缩；再放不下时出现左右滚动箭头和"全部标签"下拉列表。

## 2. 每个标签页显示什么

### 左侧竖排（展开）时

```
┌──────────────────────────────┐
│ ✳  重构标签页布局        ● 2m │  ← 第 1 行：图标 + 标题 + 状态
│    mooncli · main · claude   │  ← 第 2 行：目录 · git 分支 · 正在运行的程序
└──────────────────────────────┘
```

- **图标**：根据正在运行的程序（见第 4 节）。
- **标题**：按第 3 节的规则决定。
- **状态**（右侧）：
  - 空闲：什么都不显示
  - 运行中：一个缓慢呼吸的小点 + 已运行时长（超过 10 秒才显示）
  - 刚结束：成功显示 ✓、失败显示 ✗ 和退出码，5 秒后淡出（当前标签页）或一直保留到你切过去（后台标签页）
  - **等你操作**：Agent 在等你确认、或程序响铃，显示醒目的强调色小点
- **第 2 行**：当前目录（只显示最后一级，悬停看完整路径）、git 分支（有改动时分支名后加 `*`）、前台程序名；ssh 时显示 `user@host`。

### 顶部横排时

只显示图标 + 标题 + 状态点，悬停时出现浮窗显示第 2 行的信息。

## 3. 标题怎么定

很多程序会自己设置终端标题，比如 Claude Code 会把标题设成当前任务的简短概括，Codex 等工具也可能这么做。mooncli 按这个优先级选标题：

1. **用户手动改过的标题**（双击标签改名）——永远最优先，直到用户清除。
2. **程序设置的标题**（OSC 0 / OSC 2）——只在程序运行期间有效，程序退出后自动失效。
3. **自动生成**：`目录名`，前台有程序时是 `程序名 · 目录名`。

处理程序标题时的细节：

- pwsh 本身也会设标题（比如默认的 `pwsh` 或完整路径），这种"没信息量"的标题会被识别出来并忽略，退回自动生成。
- 有些程序会在标题前面加状态符号（比如旋转的点、✳），这部分单独拆出来做成"活动状态"，标题文字本身保持稳定，避免标签宽度来回抖。拆分规则可配置（正则）。**【待核实各工具的具体格式】**
- 标题变化做 150ms 防抖，避免程序高频刷新时闪烁。
- 设置项 `tabs.titleSource` 可选：`auto`（上面的规则）、`program`（总用程序设置的）、`directory`（总用目录）、`static`（固定配置档名）。

## 4. 识别正在运行什么

两个信号互相补充：

| 信号 | 来源 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **命令文本** | shell 集成在执行前发来的 `cmd` | 立刻知道，还知道参数 | 只知道"敲了什么"，`npm run dev` 里面实际跑的是什么不知道 |
| **进程树** | Rust 端每 1 秒扫描该会话 pwsh 的所有子孙进程（Toolhelp32 快照） | 准确知道实际在跑什么 | 有 1 秒延迟 |

确定"前台程序"的规则：在 pwsh 的子孙进程里，去掉 `conhost.exe`、`OpenConsole.exe` 这类辅助进程，取**最新启动的、最深的**那个。再用一张映射表把可执行文件名对应到"程序类型"：

| 程序类型 | 识别方式 | 图标 |
| --- | --- | --- |
| Claude Code | `claude.exe`，或 `node.exe` 的命令行里有 `@anthropic-ai/claude-code` | Claude 风格图标 |
| Codex | `codex.exe`，或 `node.exe` 命令行里有 `@openai/codex` | Codex 风格图标 |
| ssh | `ssh.exe` | 服务器 |
| 编辑器 | `vim` `nvim` `hx` `micro` | 编辑器 |
| 包管理/构建 | `npm` `pnpm` `cargo` `dotnet` … | 对应语言 |
| Python / Node | `python.exe` `node.exe`（其它情况） | 对应语言 |
| git | `git.exe` | git |
| 空闲 | 没有子进程 | 配置档的图标（默认 `>_`） |

- 映射表放在设置里，用户可以加自己的程序和图标。
- 关于 Agent 图标：内置图标用风格化的简单图形（比如 Claude 的星芒、Codex 的花括号），不直接放官方 logo；用户可以自己替换成任意图片。
- 进程扫描只在窗口可见时进行；后台标签页降到每 3 秒一次，节省 CPU。

## 5. "等你操作"提醒

后台跑 Agent 最怕的是：它停下来等你确认，你却不知道。mooncli 用这几个信号判断"需要你回来看一眼"：

| 信号 | 来源 |
| --- | --- |
| Claude Code 的 `Notification` 钩子（等待授权、等待输入时触发） | `mooncli-bridge notify` → 命名管道 |
| Claude Code 的 `Stop` 钩子（一轮回答结束） | 同上，显示为"完成"而不是"等你" |
| 程序响铃（BEL） | 终端输出 |
| 桌面通知序列（OSC 9 / OSC 777） | 终端输出 |
| 长时间命令结束（> 30 秒，可调） | shell 集成的 133;D |

提醒的表现（都可以单独开关）：

- 标签页上的强调色小点 + 标题加粗。
- 窗口不在前台时，任务栏图标闪烁一次 + Windows 系统通知（点击直接跳到那个标签页）。
- 收起的侧栏里，有提醒的标签图标会有一圈细光环。

Claude Code 钩子的配置由 mooncli 帮用户一键写入（见 [07](07-agent-monitor.md) 第 3 节），也可以手动配置。

## 6. 标签页操作

标签页上**右键**弹出 mooncli 自己的菜单（WebView 自带的"刷新 / 另存为 / 打印"已经去掉）：

| 菜单项 | 作用 | 状态 |
| --- | --- | --- |
| 重命名 | 就地改名，`Enter` 确认、`Esc` 取消；也可以双击标题或按 `F2` | ✅ |
| 置顶 / 取消置顶 | 置顶的标签排在最上面，和普通标签之间有一条虚线；`Ctrl+Shift+W` 关不掉（会提示"请右键关闭"），也不显示悬停的关闭按钮 | ✅ |
| 复制标签页 | 在同一目录新开一个标签页 | ✅ |
| 颜色 | 一行六个色点（取主题的红黄绿青蓝紫），图标染色、背景淡淡带一层颜色，方便分组；再点一次取消 | ✅ |
| 复制当前目录路径 | 复制后弹出"已复制"卡片 | ✅ |
| 恢复自动标题 | 改过名时出现，清掉手动名字 | ✅ |
| 关闭 / 关闭其他标签页 / 关闭下方（右侧）的标签页 | 置顶的标签不受"关闭其他""关闭下方"影响 | ✅ |

侧栏空白处右键：新标签页、标签栏放到顶部/左侧、收起/展开标签栏。

还没做的：

| 操作 | 方式 |
| --- | --- |
| 拖动排序 | 直接拖；拖到窗口外变成新窗口 |
| 分组 | 右键 → 加入分组。左侧竖排时分组可以折叠 |
| 搜索标签 | 标签多时，侧栏顶部有搜索框（`Ctrl+Shift+K`），按标题、目录、程序筛选 |

## 7. 数据结构（界面端）

```ts
interface TabState {
  id: string;                     // 等于 MOONCLI_SESSION_ID
  profile: string;
  title: {
    user?: string;                // 手动改的
    program?: string;             // 程序设置的（已去掉状态符号）
    programActivity?: string;     // 拆出来的状态符号
    auto: string;                 // 自动生成的
  };
  cwd?: string;
  git?: { branch: string; dirty: boolean };
  remote?: { user?: string; host: string };
  foreground?: { kind: ProgramKind; exe: string; pid: number; since: number };
  shellState: 'prompt' | 'running' | 'altscreen' | 'unknown';
  lastCommand?: { text: string; exitCode?: number; durationMs?: number; endedAt?: number };
  attention?: { reason: 'agent-waiting' | 'agent-done' | 'bell' | 'notify' | 'long-command'; at: number };
  color?: string;
  group?: string;
  pinned: boolean;
}
```

git 信息的获取：目录变化时由 Rust 端读 `.git/HEAD` 拿分支名（不调用 git 命令，够快）；"有没有改动"用 `git status --porcelain` 异步检查，结果缓存 5 秒，大仓库（检查超过 1 秒）自动停用改动检测。
